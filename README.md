# Twitter Sentiment Analysis and Clustering 📊
## Project Overview
Project ini berfokus pada analisis sentimen terhadap data Twitter yang diperoleh melalui proses crawling menggunakan keyword "konser". Pengguna dapat memasukkan teks sendiri untuk mendapatkan prediksi sentimen positive, negative, atau neutral menggunakan model Logistic Regression. Selain itu, project ini menyediakan fitur untuk menganalisis dataset dan melakukan K-Means clustering untuk mengelompokkan data berdasarkan karakteristik teks.

## Key Features
- 🔍 Sentiment Prediction: Pengguna dapat memasukkan teks untuk memprediksi sentimen positive, negative, atau neutral menggunakan model Logistic Regression yang telah dilatih.
- 📊 Data Analysis: Menampilkan berbagai analisis dan visualisasi dataset, seperti distribusi sentimen, kata yang sering muncul, dan WordCloud.
- 📈 K-Means Clustering: Melakukan pengelompokan data teks menggunakan metode K-Means clustering dan menampilkan hasil pengelompokannya.

## Installation
1. Clone repository:
   ```bash
    https://github.com/oyietaa/Crawling-twitter-NLP
    ```

2. Install library yang dibutuhkan:
    ```bash
    pip install -r requirements.txt
    ```
    
## How to Run
1. Jalankan aplikasi Streamlit menggunakan perintah:
    ```bash

    ```
